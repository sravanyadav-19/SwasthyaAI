## 🌟 Overview  
**SwasthyaAI** is an AI-powered emotional wellness web app that helps users reflect on their daily emotions, track mood trends, and receive personalized wellness suggestions — combining empathy with artificial intelligence.  

Developed for **InnovateX Hackathon (VIT-AP 2025)** by  
👨‍💻 Rajesh · 👨‍💻 Sravan · 👩‍💻 Susmitha

---

## 🚀 Features  
✅ **AI Sentiment Analysis:** Detects emotional tone from journal entries.  
📊 **Mood Dashboard:** Visualizes emotional trends and history.  
🌿 **Wellness Suggestions:** Recommends relaxation or meditation content.  
🔒 **Privacy-Focused:** Local data handling for user comfort.  
🎨 **Clean UI:** Simple, distraction-free interface.

## ⚙️ Installation & Setup  

### 🔹 Clone the Repository  
```bash
git clone https://github.com/sravanyadav-19/SwasthyaAI.git
cd SwasthyaAI
```
### 🔹 Create Virtual Environment
```bash
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate
```
### 🔹 Install Dependencies
```bash
pip install -r requirements.txt
```
🔹 Run the App
```bash
python backend/app.py
```
